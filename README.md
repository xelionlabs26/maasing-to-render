# Massing Studio

Live: https://xelionlabs26.github.io/maasing-to-render/

Turn an architect's massing into a photoreal render, lifestyle shots and Instagram reels — without changing its form. Runs entirely in the browser on fal.ai (Nano Banana Pro, Nano Banana 2, Kling 2.5 Turbo Pro).

## Put it online with GitHub Pages (about 3 minutes)
1. On github.com, click **+ → New repository**. Name it `massing-studio`, keep it **Public**, click **Create repository**.
2. Click **uploading an existing file**, drag in `index.html` (and this README), then **Commit changes**.
3. Open **Settings → Pages**. Under *Build and deployment* choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. After about a minute your link appears there: `https://YOUR-USERNAME.github.io/massing-studio/`.
5. Open the link, click **Settings**, paste your fal.ai key, click **Save and test**.

## Your key
The key is saved only in the browser where you paste it — it is never in this file or on GitHub, so the public repository is safe. Anyone who opens the link needs their own key (or uses yours on your device). Don't save it on a shared computer. Every render, shot and reel is billed to that fal.ai balance.

## If something says "isn't available"
The image-reading model (it reads the massing and checks every picture) is set in **Settings → Image-reading model**. If fal.ai reports it unavailable, enter another vision model from fal.ai's OpenRouter router.
